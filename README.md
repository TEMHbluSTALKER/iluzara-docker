## О проекте

Учебный проект по контейнеризации веб-сайта компании **«Илюзара»**, занимающейся контрольно-кассовой техникой и её обслуживанием.

Цель работы — создать собственный Docker-образ, запустить сайт в контейнере Nginx и подготовить проект к размещению на GitHub.

## Структура проекта

```text
DockerSite/
├── Dockerfile                 # Сборка образа с сайтом
├── compose.yaml               # Настройки запуска контейнера
├── README.md                  # Описание проекта
└── site/                      # Файлы сайта
    ├── img/                   # Изображения и иконки
    ├── index.html             # Главная страница
    ├── atol-products.html     # Каталог продукции АТОЛ
    ├── contacts.html          # Контакты
    ├── service-and-support.html # Сервис и поддержка
    ├── styles-index.css                # Главная страница. Стиль
    ├── styles-atol-products.css        # Каталог продукции АТОЛ. Стиль
    ├── styles-service-and-support.css  # Сервис и поддержка. Стиль
    └── styles-grid.css                 # Контакты. Стиль
```

## Как запустить

**Что потребуется:** установленный и запущенный [Docker Desktop](https://www.docker.com/products/docker-desktop/) с поддержкой Linux-контейнеров.

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив.
2. Откройте PowerShell или терминал VS Code в папке с файлом `compose.yaml`.
3. Соберите образ и запустите контейнер:

   ```powershell
   docker compose up -d --build
   ```

4. Откройте сайт в браузере: **http://localhost:8080**.

Для остановки и удаления контейнера:

```powershell
docker compose down
```

## Страницы сайта

| Раздел | Адрес после запуска |
|---|---|
| Главная | [localhost:8080](http://localhost:8080/) |
| Каталог АТОЛ | [localhost:8080/atol-products.html](http://localhost:8080/atol-products.html) |
| Контакты | [localhost:8080/contacts.html](http://localhost:8080/contacts.html) |
| Сервис и поддержка | [localhost:8080/service-and-support.html](http://localhost:8080/service-and-support.html) |

> **Примечание:** адрес `localhost` работает на том компьютере, где запущен контейнер. Публикация исходников на GitHub сама по себе не размещает сайт в интернете.

## Основные команды

| Команда | Назначение |
|---|---|
| `docker compose build` | Собрать образ из `Dockerfile` |
| `docker compose up -d` | Запустить контейнер в фоновом режиме |
| `docker compose ps` | Проверить состояние сервиса |
| `docker images` | Показать локальные образы |
| `docker ps` | Показать работающие контейнеры |
| `docker compose logs` | Посмотреть журнал работы Nginx |
| `docker compose down` | Остановить и удалить контейнер и сеть проекта |

## Как это устроено

- **Dockerfile** берёт официальный базовый образ `nginx:alpine`, копирует файлы из папки `site/` в `/usr/share/nginx/html/` и объявляет порт `80`.
- **Docker Compose** собирает образ, создаёт контейнер `iluzara-web` и перенаправляет порт `8080` компьютера на порт `80` контейнера.
- **Nginx** отдаёт HTML, CSS и изображения браузеру.

## Ход выполнения работы

1. Установлен Docker Desktop с WSL 2.
2. Проверена установка командами `docker --version`, `docker compose version` и `docker run hello-world`.
3. Запущен тестовый контейнер Nginx, проверена стандартная страница веб-сервера.
4. Подготовлены HTML, CSS и изображения сайта «Илюзара».
5. Вручную созданы файлы `Dockerfile` и `compose.yaml`.
6. Выполнена сборка командой `docker compose build`.
7. Контейнер запущен командой `docker compose up -d`.
8. Проверено состояние контейнера командой `docker compose ps` и открыта главная страница на `http://localhost:8080`.
