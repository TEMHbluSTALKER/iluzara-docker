# iluzara-docker
Структура проекта

Dockerfile — инструкции для сборки собственного Docker-образа на основе Nginx.

compose.yaml — конфигурация Docker Compose для создания и запуска контейнера.

.gitignore — список файлов, исключаемых из Git.

site/ — файлы веб-сайта «Илюзара» (HTML, CSS, изображения).

README.md — описание проекта и порядка его запуска.

Пошаговый ход работы

Установлен Docker Desktop для Windows с использованием WSL 2.

Проверена работоспособность Docker командами docker --version, docker compose version и docker run hello-world.

Загружен и запущен тестовый контейнер Nginx. Проверена доступность стандартной страницы по адресу http://localhost:8080.

Создана рабочая директория DockerSite, в которую помещены HTML, CSS и изображения веб-сайта «Илюзара».

Создан Dockerfile на основе образа nginx:alpine. С помощью инструкции COPY файлы сайта добавлены в Docker-образ.

Создан файл compose.yaml с настройками сервиса web, именем контейнера iluzara-web и пробросом порта 8080:80.

Выполнена сборка собственного образа командой docker compose build.

Контейнер запущен в фоновом режиме командой docker compose up -d.

Выполнена проверка созданного образа и работающего контейнера командами docker images, docker ps и docker compose ps.

Проверена работа главной страницы веб-сайта в браузере по адресу http://localhost:8080.

Запуск проекта

Для запуска необходимо установить Docker Desktop, скачать репозиторий и открыть терминал в корневой директории проекта.

Сборка и запуск контейнера:

docker compose up -d --build

Проверка состояния контейнера:

docker compose ps

Просмотр списка образов:

docker images

Просмотр работающих контейнеров:

docker ps

Остановка и удаление контейнера:

docker compose down

После запуска веб-сайт доступен по адресу:

http://localhost:8080

Результат работы

Создан собственный Docker-образ dockersite-web со статическим веб-сайтом «Илюзара». Контейнер iluzara-web успешно запущен с использованием Docker Compose. Подтверждена доступность главной страницы через веб-сервер Nginx.
